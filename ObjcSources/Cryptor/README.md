# 📂 Cryptor

[![Open SKSecurity.h](https://img.shields.io/badge/Open-SKSecurity.h-blue)](SKSecurity.h)

Implements SKSecurity encryption and decryption through CommonCrypto.

Read the header for the AES key sizes and Objective-C method signatures. The implementation converts string inputs to buffers before calling CommonCrypto.
