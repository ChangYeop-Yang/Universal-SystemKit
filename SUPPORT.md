## 💬 Ask a question

Use GitHub Issues for public questions about installation, SwiftPM configuration, API usage, and integration. This is the public support channel while GitHub Discussions is unavailable.

Search existing issues first. If an issue already covers your question, add any new details there. For a new question, explain what you want to do, which product or API you are using, and what you have tried. [Search GitHub Issues](https://github.com/ChangYeop-Yang/Universal-SystemKit/issues?q=is%3Aissue)

## 🐛 Report a bug

Search open and closed issues for the API name or error message. If possible, check whether the bug still occurs on the latest stable release. If you cannot update, include the version you use and the reason you need to stay on it. [GitHub Issues](https://github.com/ChangYeop-Yang/Universal-SystemKit/issues)

## 💡 Request a feature

Search for similar proposals, then open a GitHub issue describing the problem, who would use the feature, your proposed approach, and any alternatives you considered. For an API proposal, a short example of how an app would call it helps explain the request. Mention any Apple platform requirements you know about. Maintainers consider fit with the package, feasibility, and upkeep. [GitHub Issues](https://github.com/ChangYeop-Yang/Universal-SystemKit/issues)

## 🔒 Report a security issue privately

> [!IMPORTANT]
> Keep suspected vulnerabilities and related evidence out of public issues and pull requests. Use the private reporting instructions and response timeline in the [security policy](SECURITY.md).

## 📦 Check your version

Check the version or revision pinned for this package in your app's `Package.resolved`. [Latest stable release](https://github.com/ChangYeop-Yang/Universal-SystemKit/releases/latest)

| Version | Support status |
| --- | --- |
| Latest stable release | Primary focus for usage questions and bug reports. |
| Earlier releases | Limited support. If a problem persists on the latest stable release, include both versions you checked. |
| Prereleases or commits on `main` | Best effort. Include the exact tag or commit so maintainers can identify the code you used. |
| Versions marked unsupported | Update to the latest stable release for general support. Private security reports are welcome for any version. [Security policy](SECURITY.md) |

## ⏱️ Response times

This project offers community support only. Volunteers review public questions and issues as time allows. Timing varies by availability, impact, and project priorities. Public replies and fixes have no guaranteed deadline.
